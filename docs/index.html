Dense GitHub

Turn any folder into an info server for your agents.

Dense spins up MCP servers that expose search and read tools over your information sources, so agents can find and use what they need without you pasting it into a prompt.

Download the CLI View on GitHub

What it does

Point Dense at a local folder and it connects it to a server. The server speaks MCP, so any compatible agent or client can search and read your files through it. The CLI works like git: you connect folders, sync changes, and keep the server up to date.

  • Connect local folders with a git-like workflow
  • Each source becomes an MCP server with search and read tools
  • Works with any MCP-compatible agent
  • Open source

Get started

# install (replace with your real install command)
curl -fsSL https://github.com/YOUR-ORG/dense/releases/latest/download/install.sh | sh

# connect a folder
cd ~/notes
dense init
dense add .

# push it to your server
dense push

Then add the Dense URL to your agent's MCP config and it can search and read the folder right away.

{
  "mcpServers": {
    "notes": { "url": "https://your-server-url/mcp" }
  }
}

Commands

  • dense init sets up Dense in the current folder
  • dense add <path> adds files to the source
  • dense status shows what has changed since the last push
  • dense push syncs your folder to the server

Where it's going

Folders are the start. Dense is meant to be the easiest way to give agents access to any information source, including docs, wikis, repos, tickets, and databases through info servers with consistent search and read tools. One place to connect, manage, and share what your agents know.
